END-TO-END PIPELINE

파이프라인의 처음부터 끝까지,
한 사람의 책임으로.

단계마다 담당자가 바뀌면 의도가 흐려집니다. 데이터에서 배포까지 같은 설계 원칙으로 이어 갑니다.

  1. 01 / DATA 데이터 수집·합성 부족한 현장 데이터는 합성 이미지로 채웁니다. synthetic data
  2. 02 / DATASET 데이터셋 관리 라벨링과 버전 관리로 재현 가능한 학습 기반. versioning
  3. 03 / MODEL 모델 학습 문제에 맞는 딥러닝 모델 설계·학습·평가. Python · DL
  4. 04 / BACKEND 백엔드 · API 모델을 서비스로 만드는 서버와 연계. API · EAI
  5. 05 / FRONTEND 프론트엔드 현장 사용자가 바로 쓰는 화면. web · mobile
  6. 06 / EDGE 엣지 배포 모바일·현장 기기에서 직접 추론. on-device
